## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.

# WAYWE Service Livewire

This is the separate Livewire-based application copy of the existing
`service-job-system`. The original project is unchanged. Laravel controllers,
models, workflows, and views are retained; application pages and the customer,
job, and workflow forms are served through Livewire.

## Local setup

Requirements: PHP 8.2+, Composer, Node.js, and npm.

1. Configure `.env` with the same MySQL connection used by `service-job-system`.
   Keep this app's `APP_KEY` separate from the original application's key.
2. Install dependencies and build assets:

   ```bash
   composer install
   npm install
   npm run build
   ```

3. Start this copy on its separate local port:

   ```bash
   php artisan serve --port=8001
   ```

## Shared database

Both applications use the same MySQL database and therefore see the same users,
customers, jobs, and payments. A change made in either application is visible
to the other. Do not run `migrate:fresh`, `db:wipe`, or seeders against this
shared database. No migrations or seeders were run while creating this copy.
The test suite uses an in-memory SQLite database.

## Database setup

For a completely new installation only, configure MySQL in `.env` and create
the application tables with:

```bash
php artisan migrate
```

Do not run this against the database already used by `service-job-system`
unless you have confirmed its schema is missing required migrations and have a
database backup.

Tests continue to use an in-memory SQLite database.
